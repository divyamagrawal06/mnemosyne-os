# Product

## Register

product

## Users

The project author demonstrates a research OS to a teacher and technical reviewers. The same local interface supports development checks. The existing presentation guide establishes a classroom walkthrough with three acts: kernel boot, host correctness tests, and Wasmi replay.

## Product Purpose

Make the working prototype observable and runnable without memorizing terminal commands. Preserve raw evidence, show the source and age of each result, and explain the boundary between the QEMU kernel and host experiments. The CLI remains the execution interface beneath the dashboard.

## Brand Personality

Precise, calm, inspectable. Reuse the existing presentation's restrained paper, ink, and green palette. The dashboard serves the research demonstration, with no promotional claims beyond the code and evidence.

## Anti-references

Avoid a mock OS desktop, fabricated telemetry, decorative performance charts, or controls that pretend planned subsystems exist. Do not label a saved result as a current live run. Avoid speculative AI chat controls while the recovery planner is unimplemented.

## Design Principles

- Put the runnable demo and its outcome first.
- Keep the selected evidence source visible across every detail view.
- Give every displayed conclusion an inspectable result or log.
- Separate current implementation from research milestones.
- Preserve the existing PowerPoint and command-based presentation routes.

## Accessibility & Inclusion

The presentation guide calls for readable classroom display. Use keyboard-accessible native controls, visible focus, text labels alongside status colors, adequate contrast, responsive layout, and reduced-motion support. These are implementation defaults; the repository specifies no additional audience accommodations.

## Context basis

Derived from README.md, AGENTS.md, docs/implementation-status.md, presentation/demo-runbook.md, and the existing deck's design and source notes. Guided presentation is the initial default; detail views also support development.
